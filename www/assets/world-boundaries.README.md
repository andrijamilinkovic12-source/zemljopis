# Granice sveta za Put oko sveta

Ovaj fajl je lokalni GeoJSON izvor za MapLibre prikaz bez natpisa.

- Polazni skup: Natural Earth, `ne_50m_admin_0_countries`.
- Prikaz Balkana je pripremljen za ovu igru u skladu sa dostavljenom UN referencom: poligoni Srbije i Kosova su spojeni, pa se između njih ne iscrtava posebna državna granica.
- Ponovna izrada: `npm run build:world-boundaries`.

Pre objave, političke granice treba proveriti prema odobrenom, licenciranom autoritativnom vektorskom izvoru.
